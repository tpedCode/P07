TESTS LOCAUX — API HOME CREDIT SCORING
======================================================================


PROCÉDURE — REFAIRE LES TESTS LOCAUX
--------------
1. Ouvrir le projet P07 dans VS Code.
2. Ouvrir un terminal dans VS Code.
3. Activer l'environnement virtuel : ```bash source venv/Scripts/activate````
4. Démarrer l'API : ```bash uvicorn api_home_credit_scoring:app --reload ```
5. Vérifier dans le terminal que l'API est démarrée : ```text Application startup complete. ```
6. Ouvrir Swagger dans le navigateur : [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
7. Tester les endpoints dans Swagger, dans cet ordre :
   * `GET /` → Test 1
   * `GET /health` → Test 2
   * `POST /predict` → Tests 3 à 14
8. Pour chaque test `POST /predict` :
   * Cliquer sur **Try it out**.
   * Coller le JSON du test.
   * Cliquer sur **Execute**.
   * Relever le code HTTP.
   * Relever le **Response body**.
   * Copier le résultat observé dans le compte rendu.
9. Vérifier que le résultat correspond au comportement attendu du test.
10. Une fois tous les tests terminés, arrêter l'API avec : ```text CTRL + C```
