   - GET /

   - POST /predict

10. Cliquer sur **Try it out**.
11. Pour chaque test de prédiction :
    - Coller le JSON du test.
    - Cliquer sur **Execute**.
    - Relever le code HTTP.
    - Relever le **Response body**.
    - Copier le résultat observé dans le compte rendu.
12. Réaliser les tests dans l'ordre
13. Vérifier que les résultats obtenus sur Render sont cohérents avec les résultats des tests locaux.
