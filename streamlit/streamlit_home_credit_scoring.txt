## PROCEDURE — OUVRIR ET UTILISER L'INTERFACE STREAMLIT
-------------------------------------------------------

1. Ouvrir le projet P07 dans VS Code.
2. Ouvrir un terminal dans VS Code.
3. Vérifier que le terminal se trouve bien dans le dossier du projet P07 : ```bash pwd````
4. Vérifier que le dossier Streamlit contient le fichier : ```text streamlit/└── app.py```
5. Vérifier que l'environnement virtuel contenant Streamlit et Requests est disponible.
6. Activer l'environnement virtuel : ```bash source mlflow_env/Scripts/activate```
7. Vérifier que Streamlit est disponible : ```bash pip show streamlit```
8. Vérifier que Requests est disponible : ```bash pip show requests```
9. Démarrer l'interface Streamlit : ```bash streamlit run streamlit/app.py```
10. Ouvrir l'interface Streamlit dans le navigateur.
11. Vérifier que la page `Home Credit Scoring — API Test` est accessible.
12. Vérifier la santé de l'API depuis l'interface.
13. Vérifier que l'API est indiquée comme opérationnelle.
14. Vérifier les informations affichées sur le modèle :
    * modèle utilisé ;
    * nombre de variables ;
    * nombre de variables obligatoires ;
    * nombre de variables recommandées ;
    * seuil métier.
15. Renseigner un identifiant de test.
16. Saisir les 5 variables obligatoires :
    * PAYMENT_RATE ;
    * EXT_SOURCE_MEAN ;
    * DAYS_BIRTH ;
    * DAYS_EMPLOYED ;
    * AMT_ANNUITY.
17. Lancer le test de prédiction.
18. Vérifier les données envoyées à l'API.
19. Vérifier que la prédiction est réalisée avec succès.
20. Vérifier les résultats du scoring :
    * probabilité de défaut ;
    * seuil métier ;
    * décision ;
    * couverture des variables ;
    * complétude des données ;
    * variables recommandées absentes ;
    * variables optionnelles absentes ;
    * warning.
21. Vérifier la réponse complète retournée par l'API.
22. Comparer les résultats affichés dans Streamlit avec ceux obtenus directement dans Swagger sur Render.
23. Vérifier que les résultats sont identiques ou cohérents.
24. Conserver les résultats pour le compte rendu et les captures d'écran de soutenance.
